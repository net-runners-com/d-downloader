# ダイレクトアカデミー 講座ダウンローダー（Chrome拡張）v0.2

dpub.jp（ダイレクトアカデミー）に**自分のアカウントでログインした状態**で、購入済み講座の動画を保存する拡張です。ページ内のログインセッションをそのまま使うので、拡張側での認証設定は不要です。

## できること

- **講座を複数選択**（ライブラリのカードにチェック → まとめてダウンロード）
- **サブスク講座も対応**（「購読中のサブスクリプション講座」= エキスパート・シークレッツ等）。
  章立てが多いアコーディオン形式でも全セクションを自動展開して全チャプターを列挙。公開前(【○/○公開】)は自動でスキップ。
- **PART/チャプターを選択**（ダウンローダー画面でチェック。大量リスト向けに「全選択／全解除」あり）
- **任意フォルダに保存**（File System Access API。Downloads外・外付けドライブも可。一度選べば記憶）

## 使い方

1. `chrome://extensions` → 右上「デベロッパーモード」ON → 「パッケージ化されていない拡張機能を読み込む」→ この `extension/` フォルダを選択
2. dpub.jp にログイン
3. **ライブラリ**（https://dpub.jp/library/）で講座カードのチェックを付ける → 画面下部の「選択した講座をダウンロード」
   - 1講座だけなら、カード右上の **⬇**、または講座ページ左下の「**⬇ この講座を保存**」でも可
4. **ダウンローダー画面**が開く →「保存先フォルダを選ぶ」→ 欲しいPARTにチェック →「ダウンロード開始」

## 保存形式

- 選んだフォルダ内に `<講座名>/01_<PART名>.<mp4|ts>` … 各PARTを連番で保存
- ダウンローダー画面の「形式」で **MP4**（既定）／**TS** を選択
  - **MP4**: 同梱の mux.js で MPEG-TS → fragmented MP4 に**再エンコード無し**で変換（最高画質、H.264/AAC）。QuickTime/ブラウザ/VLC で再生可
  - **TS**: セグメントをそのまま連結（最軽量・最も確実）。MP4化したい場合は無劣化で `ffmpeg -i x.ts -c copy x.mp4`

## 仕組み

- 講座のPART一覧は**描画後のDOMにしか無い**（indexのHTMLに `/contents/` は無く、`X-Frame-Options: DENY` でiframe不可）。
  ライブラリからのクリック時は講座ページを**バックグラウンドタブで開いてDOMから一覧取得**し、取得後にそのタブを閉じます。
- 各コンテンツページのHTMLに Wistia の動画IDが埋め込まれており、`fetch`（同一オリジン＝ログイン状態）で抽出します。
- 動画は Wistia の HLS。**ダウンローダーページ（拡張オリジン）**が最高画質バリアントの `.ts` セグメントを
  先読み並列で取得しつつ順序どおりに `WritableStream` へ書き出し、選んだフォルダへ直接ストリーム保存します（低メモリ）。
  variant/セグメントはCORSヘッダが無いため、`host_permissions` を持つ拡張ページから取得しています。

## 構成

| ファイル | 役割 |
|---|---|
| `manifest.json` | MV3 設定・権限（storage / tabs、host: dpub.jp と *.wistia.*） |
| `content.js` | ライブラリの複数選択UI・講座ページの列挙とボタン |
| `background.js` | バックグラウンドタブでの列挙・ジョブ管理・ダウンローダー起動 |
| `downloader.html` / `downloader.js` | 保存先選択・PART選択・HLS取得→フォルダへストリーム保存 |
| `popup.html` | ライブラリへのリンクと簡易説明 |

## 検証済み / 未検証

- 検証済み: HLS結合（実URLで PART1 436セグメント→尺一致 / PART2 537セグメント→尺一致・デコードエラー無し）、
  DOM一覧列挙＋Wistia ID抽出（実ブラウザで5PART正しく取得）、先読み並列＋順序書き込みの整合性
- 未検証: 拡張ロード後の end-to-end（File System Access のフォルダ選択・書き込み、chrome.tabs 連携）。標準的なWeb/MV3 APIで実装。

## 注意

購入済みコンテンツの個人利用（バックアップ・オフライン視聴）を想定しています。再配布はしないでください。
任意フォルダ保存には Chrome/Edge 等の File System Access 対応が必要です。

## うまく動かない時

- **「connect.facebook.net … Content Security Policy」エラー**: これは dpub.jp サイト自身がFacebookピクセルを弾いている無関係なログ。拡張とは関係なく、無視してよい。
- **ボタンを押しても何も起きない / ダウンローダーが開かない**:
  1. 拡張を更新したら **dpub.jp のタブを必ずリロード**（古いコンテンツスクリプトが残っていると `Extension context invalidated` で無反応になる）。
  2. `chrome://extensions` でこの拡張の「Service Worker」→ Console にエラーが出ていないか確認。
  3. サブスク講座は解析（全チャプター展開＋取得）に十数秒かかる。ダウンローダーは即開き、各講座は最初「解析中…」表示 → 順次PARTが埋まる。
