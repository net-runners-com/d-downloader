# ダイレクトアカデミー 講座ダウンローダー（Chrome拡張）v0.3.3

dpub.jp（ダイレクトアカデミー）に**自分のアカウントでログインした状態**で、購入済み講座の動画を保存する拡張です。ページ内のログインセッションをそのまま使うので、拡張側での認証設定は不要です。

## できること

- **講座を複数選択**（ライブラリのカードにチェック → まとめてダウンロード）
- **サブスク講座も対応**（「購読中のサブスクリプション講座」= エキスパート・シークレッツ等）。
  章立てが多いアコーディオン形式でも全セクションを自動展開して全チャプターを列挙。公開前(【○/○公開】)は自動でスキップ。
- **関連教材・資料も一緒に保存**（コンテンツページの「関連教材・資料」の PDF / PNG / ZIP などを検出し、
  動画と同じフォルダへ同じ連番を付けて保存。資料だけのコンテンツも一覧に出ます）
- **章（アコーディオンの項目）ごとにフォルダ分け・選択**（保存先も `<講座名>/<章名>/` に自動で分岐。
  「講座ごとのみ」に切り替えも可）
- **ツリー表示（講座 > 章 > PART > 資料）**
  - 親のチェックは配下すべてに反映。子を部分的に外すと親は「−」（中間状態）になり、`（3/6）` と選択数を表示
  - 見出しクリック／▼で**折りたたみ**。フッタの「たたむ／展開」で一括
  - 「全選択／全解除／動画のみ／資料のみ」ボタンあり
- **任意フォルダに保存**（File System Access API。Downloads外・外付けドライブも可。一度選べば記憶）

## 使い方

1. `chrome://extensions` → 右上「デベロッパーモード」ON → 「パッケージ化されていない拡張機能を読み込む」→ この `extension/` フォルダを選択
2. dpub.jp にログイン
3. **ライブラリ**（https://dpub.jp/library/）で講座カードのチェックを付ける → 画面下部の「選択した講座をダウンロード」
   - 1講座だけなら、カード右上の **⬇**、または講座ページ左下の「**⬇ この講座を保存**」でも可
4. **ダウンローダー画面**が開く →「保存先フォルダを選ぶ」→ ツリーで欲しい章／PART／資料にチェック →「ダウンロード開始」
   - 「フォルダ」で **講座 / 章ごと**（既定）か **講座ごとのみ** を選択
   - 資料の取得元ホストによっては、開始時に Chrome の権限ダイアログが出ます（許可しなくても dpub.jp のタブ経由で取得を試みます）

## 保存形式

```
<選んだフォルダ>/<講座名>/<章名>/01_<PART名>.mp4              ← 資料なし: そのまま置く
                              /02_<PART名>/                 ← 資料あり: PARTごとにフォルダ
                                  02_<PART名>.mp4
                                  ExpertSecrets_..._slides.pdf
                                  ExpertSecrets_..._image.png
```

- **資料があるPARTは、その動画タイトルのフォルダを作り、動画と資料をまとめて保存**（資料が無いPARTは従来どおり直置き）
- 章が無い講座（通常講座）や「講座ごとのみ」指定時は `<講座名>/` 直下に保存
- 連番は章ごとに 01 から振り直し（章分けしない場合は講座全体の通し番号）
- フォルダ内の資料は元のファイル名そのまま（フォルダで対応が分かるため連番は付けない）
- ダウンローダー画面の「形式」で **MP4**（既定）／**TS** を選択
  - **MP4**: 同梱の mux.js で MPEG-TS → fragmented MP4 に**再エンコード無し**で変換（最高画質、H.264/AAC）。QuickTime/ブラウザ/VLC で再生可
  - **TS**: セグメントをそのまま連結（最軽量・最も確実）。MP4化したい場合は無劣化で `ffmpeg -i x.ts -c copy x.mp4`

## 仕組み

- 講座のPART一覧は**描画後のDOMにしか無い**（indexのHTMLに `/contents/` は無く、`X-Frame-Options: DENY` でiframe不可）。
  ライブラリからのクリック時は講座ページを**バックグラウンドタブで開いてDOMから一覧取得**し、取得後にそのタブを閉じます。
- 各コンテンツページのHTMLに Wistia の動画IDと「関連教材・資料」のファイルURLが埋め込まれており、
  `fetch`（同一オリジン＝ログイン状態）で抽出します。資料は**全コンテンツページ**を個別に見て集めます。
  - まずHTML内の `\uXXXX` エスケープを復号し、**「関連教材・資料」の見出し位置から後ろ8000文字**だけを走査。
    サイドバーや先読みされた別レッスンのファイルが混ざるのを防ぎます（見出しが無い／その窓で0件なら全文走査にフォールバック）
  - 拾い方は3通り: 絶対URL / 相対パス / `{"name":"x.pdf", "url":"..."}` 形式のJSONオブジェクト
    （署名付きで拡張子が無いURLでも、name側にファイル名があれば拾えます）
  - ロゴ/favicon/サムネ等のサイト共通アセット、および `f2y0kMyr6LTyNL2v1gFbCA==.png` のような
    ハッシュ/base64ファイル名のCDN画像は除外 + 「ほぼ全PARTに出てくる同一URL」は講座資料ではないと見なして除外
    （各レッスン固有の資料はURLが違うので、この除外には掛かりません）
- 章（フォルダ名）は、講座ページのアコーディオンの見出しボタン（`aria-controls`）とその中身の対応から決定します。
- 資料は拡張ページから直接 `fetch`、ダメなら dpub.jp のタブ経由（`chrome.tabs.sendMessage`）で取得します。
  拡張オリジンからの取得は cross-site 扱いで SameSite Cookie が落ちるため、ログインが要る資料はこの経路になります。
- 動画は Wistia の HLS。**ダウンローダーページ（拡張オリジン）**が最高画質バリアントの `.ts` セグメントを
  先読み並列で取得しつつ順序どおりに `WritableStream` へ書き出し、選んだフォルダへ直接ストリーム保存します（低メモリ）。
  variant/セグメントはCORSヘッダが無いため、`host_permissions` を持つ拡張ページから取得しています。

## 構成

| ファイル | 役割 |
|---|---|
| `manifest.json` | MV3 設定・権限（storage / tabs、host: dpub.jp と *.wistia.*、資料ホスト用の optional_host_permissions） |
| `content.js` | ライブラリの複数選択UI・講座ページの列挙（章＋資料URL）・資料取得の中継 |
| `background.js` | バックグラウンドタブでの列挙・ジョブ管理・ダウンローダー起動・資料取得の中継 |
| `downloader.html` / `downloader.js` | 保存先選択・章/PART/資料選択・HLS取得→フォルダへストリーム保存・資料保存 |
| `popup.html` | ライブラリへのリンクと簡易説明 |

## 検証済み / 未検証

- 検証済み: HLS結合（実URLで PART1 436セグメント→尺一致 / PART2 537セグメント→尺一致・デコードエラー無し）、
  DOM一覧列挙＋Wistia ID抽出（実ブラウザで5PART正しく取得）、先読み並列＋順序書き込みの整合性、
  資料URL抽出ロジック（RSCペイロード相当のサンプルで、見出し直後の PDF/PNG 2件を抽出・拡張子無しの署名付きURLも
  name から復元・12000文字離れた別レッスンのファイルとロゴ/faviconを除外・見出し無しHTMLでは全文走査にフォールバック、を確認）
- 未検証: **実ページでの資料URL・章見出しの取得**（dpub.jp の実HTMLでは未確認。取れない/余計なファイルが混ざる場合は
  ダウンローダー画面のチェックを外せば除外できます）、拡張ロード後の end-to-end（File System Access の書き込み、chrome.tabs 連携）

## 注意

購入済みコンテンツの個人利用（バックアップ・オフライン視聴）を想定しています。再配布はしないでください。
任意フォルダ保存には Chrome/Edge 等の File System Access 対応が必要です。

## うまく動かない時

- **「connect.facebook.net … Content Security Policy」エラー**: これは dpub.jp サイト自身がFacebookピクセルを弾いている無関係なログ。拡張とは関係なく、無視してよい。
- **ボタンを押しても何も起きない / ダウンローダーが開かない**:
  1. 拡張を更新したら **dpub.jp のタブを必ずリロード**（古いコンテンツスクリプトが残っていると `Extension context invalidated` で無反応になる）。
  2. `chrome://extensions` でこの拡張の「Service Worker」→ Console にエラーが出ていないか確認。
  3. サブスク講座は解析（全チャプター展開＋取得）に十数秒かかる。ダウンローダーは即開き、各講座は最初スピナー付きの「解析中…」表示 → 順次PARTが埋まる。
- **資料が0件 / 変なファイルが混ざる**: 資料はHTML内のファイルURLを拡張子で拾う方式のため、サイト構造が変わると
  取りこぼし・誤検出が起きえます。誤検出はチェックを外すだけでOK。0件の場合はコンテンツページのHTMLに資料URLが
  無い（クライアント側で別途取得している）可能性があります。
- **資料だけ「エラー: HTTP 403」**: 資料が署名付きURLの場合、時間切れの可能性。講座を解析し直してください。
